1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------

This document confirms delivery of the Hammer Candle Backtest Dashboard for
candlestick strategy research on historical XAUUSD data, plus an integrated
Live Trading module for MetaTrader 5 (MT5).

What you receive:

  • Desktop application (PySide6 / Qt) with parameter tabs, live pattern
    preview, multi-timeframe backtests, metrics, charts, and run history
  • Three pattern engines: Hammer, Hammer with candles, and Doji
  • SuperTrend and VWAP indicator filters (same rules in backtest and live)
  • Results broken down by timeframe, direction, session, year, and month
  • Optional Windows executable via GitHub Actions packaging
  • Live MT5 signal polling and optional order execution using the SAME
    strategy settings as backtest (with dry-run default and safety limits)

Saving a preset is optional (Run Settings). Live order risk controls live on
the Live Trading panel only — not on backtest commission / slippage fields.

Platform note:
  • Backtest and UI: macOS and Windows
  • MT5 live connection and orders: Windows only (MT5 terminal + MetaTrader5
    Python package required)

  • Run Settings tab: symbol, data folder, date range, position sizing

2.4 Indicators (SuperTrend and VWAP)

  • Indicators tab: add from dropdown; per-indicator settings

  • Filter rules documented in-app and in indicators/filter.py
  • Same filters apply in backtest and in the live signal loop when enabled


2.5 Results and reporting
-------------------------

  • Results panel (F8), separate from Live Trading
  • Metrics tabs:
      Overall · By Timeframe · By Direction · By Session · By Year · By Month
  • Colour key: green = BUY · red = SELL · blue = candle-bias exit model
  • Three exit models always reported together:
      Best case · Candle bias · Worst case
  • Session analytics (IC Markets MT5 server time):
      Asian  00:00–07:59 server
      London 08:00–15:59 server
      US     16:00–23:59 server
      Server clock is GMT+2 (winter) / GMT+3 (US daylight saving), matching
      your CSV timestamps from MT5.
  • How to read session Max DD / Return %:
      Net PnL, wins, and losses by session ADD UP to Overall.
      Max drawdown and return % by session are “as if that session alone”
      (not additive across sessions).
  • Fixed stop loss: optional fixed distance from entry (price units),
    or candle extreme (low / high) + buffer — on Entry / Exit tab
  • Trades tab: trade list (full file: trade_ledger.csv in the run folder)
  • Charts tab: thumbnails with click-to-zoom (includes session charts)
  • History tab: SQLite run_history.db with full metrics + breakdown rows
    (session, timeframe, direction, year, month); Export to Excel
  • Compare tab: Run A vs Run B — overall by exit model, plus By Session
    (worst case)
  • Toolbar: open output folder · open ledger · export last-run metrics ·
    open charts folder


2.6 Live trading (MT5)
----------------------

  • Live Trading panel (F9): strategy summary, MT5 connection, execution,
    safety limits, activity log
  • Pattern selector synced with Backtest Parameters (Hammer / Hammer with
    candles / Doji)
  • Same rules as backtest: current dashboard config or loaded preset
  • MT5: terminal path (optional), login, password, server; demo and live
    accounts supported
  • Execution: symbol, timeframe, lot size, magic number, max open positions,
    poll interval
  • Safety limits (enforced for real orders from this panel only):
      • Max trades per day
      • Max daily loss ($) — required before live orders on real accounts
      • Cooldown (minutes between trades)
      • Max spread (points)
      • Max lot cap
      • Optional: restrict to demo accounts only
  • Dry run default ON — logs signals only; no orders sent
  • Live → Performance menu (advanced): dry run, thread pool, optional Ray
  • Background worker keeps UI responsive; confirmations before live orders

  Client environment for live:

  Operating system     Windows (required for MT5 API)
  MT5 terminal         Installed and logged in (demo or live)
  Python package       pip install MetaTrader5
  macOS                Backtest / UI only; run live on Windows

8. HOW TO USE THE APPLICATION
--------------------------------------------------------------------------------

Backtest workflow
  1. Launch: python dashboard.py  (or the packaged Windows .exe)
  2. Choose pattern: Hammer · Hammer with candles · Doji
  3. Adjust Body / Wicks / Direction / Context / Entry-Exit / Timeframes
     (include timeframes and sessions you want to test)
  4. Run Backtest (F5)
  5. Review Results → Metrics (Overall, Session, Year, Month, …), Trades,
     Charts; use History / Compare for past runs
  6. Optionally save settings under Run Settings as a preset

Live workflow (Windows + MT5)
  1. Tune strategy on backtest; optionally load a preset
  2. Open Live Trading (F9); confirm strategy summary
  3. Set Safety limits (daily loss, max trades, lot cap, etc.)
  4. Keep Live → Performance → Dry run ON until the Activity log looks correct
  5. Connect MT5 → Start live; turn off dry run only when ready
     (confirmations apply)

Layout tips
  • F1 — keyboard shortcuts
  • F2 — reset panel layout
  • Drag panel titles to tab or dock side-by-side
