1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------

This document summarizes the Hammer Candle Backtest Dashboard delivered for
candlestick strategy research on historical XAUUSD data, plus an integrated
Live Trading module for MetaTrader 5 (MT5).

The application provides a modern desktop interface (PySide6/Qt), live visual
previews of pattern rules, configurable backtests, metrics and charts, run
history aligned with your Strategy Configurator workbook schema, optional
packaging as a Windows executable, and live signal polling / optional order
execution using the same strategy and indicator settings as backtest.

Work completed across phases includes full Doji support, hammer type and
direction controls, SuperTrend and VWAP indicators (extensible), results UX
(colors, trades, compare, export), optional JSON presets, and live trading
with client-facing risk limits, dry-run default, and stability-focused
threading on the live loop.

Saving a preset is optional (Run Settings). Live orders use Safety limits on
the Live Trading panel only, not backtest commission/slippage fields.

Platform note:
  - Backtest and UI run on macOS and Windows.
  - MT5 live connection and orders require Windows with the MT5 terminal and
    the MetaTrader5 Python package installed.

2.2 Pattern and preview (UI)
----------------------------

  - Candle pattern selector: Hammer and Doji; fields show/hide automatically.
  - Pattern preview — Signal Shape: Live candle from body/wick settings;
    loosest/tightest valid shapes.
  - Pattern preview — Pattern in Context: Chart per timeframe with entry, SL,
    TP, support/resistance; follows Doji style when Doji is selected.
  - Hammer — Direction tab: Green/red direction; classic vs inverted; allow or
    block BUY/SELL per type.
  - Doji — Doji Direction tab: Style and direction mode (including CANDLE_COLOR);
    per-side enable flags.
  - Body / Wicks tabs: Separate hammer and doji ratio fields with tooltips.


2.3 Timeframes and run configuration
------------------------------------

  - Single Timeframes tab: Include in run, RR multiple, Max SL ($) per timeframe.
  - Run Settings tab: Symbol, data folder, date range, sizing, overlap,
    commission, slippage, etc.
  - Optional saved parameter sets: Save/load/delete JSON in presets/ — not
    required to run backtest or start live (recommended to document approved
    setups).


2.4 Indicators (SuperTrend and VWAP)
------------------------------------

  - Extensible indicators package: config, SuperTrend, VWAP, registry, filters.
  - Indicators tab: Add from dropdown; per-indicator settings; combine filters
    (ALL / ANY) when two or more indicators are active.
  - Documented filter rules in-app and in indicators/filter.py.
  - Backtest and live: Filters apply to Hammer and Doji when indicators are
    enabled.


2.5 Results and reporting
-------------------------

  - Results panel (keyboard F8), separate from Live Trading.
  - Metrics: Overall, By Timeframe, By Direction — color key: green = BUY,
    red = SELL, blue = candle-bias exit model.
  - Trades tab: Trade list from last run (full data in trade_ledger.csv).
  - Charts tab: Thumbnails with click-to-zoom.
  - History tab: SQLite run history; double-click to open run folder; Export
    to Excel.
  - Compare tab: Two Strategy IDs side-by-side (PnL, win rate, drawdown, etc.).
  - Toolbar: Open output folder, open ledger, export last run metrics, open
    charts folder.


2.6 Live trading (MT5)
----------------------

  - Live Trading panel (keyboard F9): Strategy summary, MT5 connection,
    execution, safety limits, activity log.
  - Strategy aligned with Backtest Parameters (Hammer/Doji, indicators,
    symbol/timeframe).
  - Same rules as backtest: Current dashboard config or loaded preset.
  - MT5 connection: Terminal path (optional), login, password, server;
    demo and live/real accounts supported.
  - Execution: Symbol, timeframe, lot size, magic number, max open positions,
    poll interval.
  - Safety limits (enforced for real orders from Live panel only):
      • Max trades per day
      • Max daily loss ($) — required before live orders on real accounts
      • Cooldown (minutes between trades)
      • Max spread (points)
      • Max lot cap
      • Optional: restrict to demo accounts only
  - Dry run default ON — logs signals only; no orders sent.
  - Menu Live → Performance (advanced): dry run, thread pool, optional Ray.
  - Background worker thread keeps UI responsive; confirmations before live
    orders.

  Client environment for live:

  Requirement          Notes
  -------------------  --------------------------------------------------------
  Operating system     Windows (required for MT5 API)
  MT5 terminal         Installed and logged in (demo or live)
  Python package       pip install MetaTrader5
  macOS                Backtest/UI only; run live on Windows


2.7 Desktop layout and stability
--------------------------------

  - Dockable panels: Parameters (top), Preview (left), Results, Live Trading.
  - Drag panel titles to tab together or dock side-by-side; resize splitters.
  - F2 — Reset layout to default.
  - Window size remembered between sessions.
  - macOS: Floating separate windows disabled for stability; tabbing inside
    main window works.
  - Windows: Full dock behavior including floatable panels.


2.8 Packaging and operations

  - Folders data/, output/, plots/, presets/, run_history.db next to app or exe.
  - Windows exe build via GitHub Actions includes live modules.
  - Live activity shown in in-app Activity log; orders go to MT5 when enabled.

8. HOW THE CLIENT USES THE APPLICATION
--------------------------------------------------------------------------------

Backtest workflow
  1. Launch: python dashboard.py or packaged .exe.
  2. Choose Hammer or Doji; adjust parameter tabs; Run Backtest (F5).
  3. Review Results — Metrics, Trades, Charts; Compare past runs if needed.
  4. Optionally save settings under Run Settings as a preset file.

Live workflow (Windows + MT5)
  1. Tune strategy on backtest; optionally load preset.
  2. Open Live Trading (F9); confirm strategy summary.
  3. Set Safety limits (daily loss, max trades, lot cap, etc.).
  4. Keep Live → Performance → Dry run ON until Activity log looks correct.
  5. Connect MT5 → Start live; turn off dry run only when ready (confirmations
     apply).

Layout tips
  - F2 — reset panel layout.
  - Drag panel titles to tab or dock side-by-side.
  - F1 — keyboard shortcuts help.
